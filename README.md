# תיקון שפת הקלדה · Type Correction

מתקן מילים שהוקלדו בשפת מקלדת לא נכונה. לדוגמה, `xccv` הופך ל־`סבבה`.
עובד עם כל שפות המקלדת שמותקנות ב־Windows, בכל התוכנות.

*Fixes words typed in the wrong keyboard layout (e.g. `xccv` → `סבבה`), for any layouts installed in Windows. Local only: no network, nothing saved.*

## הורדה והפעלה
1. מורידים את `TypeCorrection.exe` מעמוד ה־**[Releases](../../releases/latest)**. לא צריך להתקין כלום.
   דרישות: Windows 10 או 11 (64 ביט), ולפחות שתי שפות מקלדת מותקנות.
2. שומרים את הקובץ בתיקייה קבועה, לא בתיקיית ההורדות, ומריצים אותו.
3. הקובץ לא חתום דיגיטלית, ולכן Windows יציג אזהרה: לוחצים **"מידע נוסף" ← "הפעל בכל זאת"**.
4. מופיע אייקון `אA` ליד השעון. כדי שהתוכנה תעלה עם המחשב: קליק ימני על האייקון ← **"הפעלה עם Windows"**.

| פעולה | מה קורה |
|---|---|
| מקלידים מילה ואז רווח או Enter | אם המילה הוקלדה בשפה הלא נכונה, היא מתוקנת ושפת המקלדת מוחלפת |
| Pause מיד אחרי תיקון | מבטל את התיקון. המילה לא תתוקן שוב עד שהתוכנה תופעל מחדש |
| Pause בכל מצב אחר | ממיר ידנית את המילה האחרונה לשפה הבאה |
| Backspace | מוחק כרגיל, בלי שום התנהגות מיוחדת |
| לחיצה כפולה על האייקון | השהיה או הפעלה |
| קליק ימני על האייקון | הפעלה עם Windows, השפות שזוהו, תוכנות מוחרגות, יציאה |

## איך התוכנה מחליטה
- עובדת עם כל שפות המקלדת שמותקנות ב־Windows.
- משתמשת בבודק האיות המובנה של Windows. מתקנת רק אם המילה כפי שהוקלדה **אינה** מילה תקינה, ואותם מקשים בשפה אחרת **כן** יוצרים מילה תקינה.
- מילה שתקינה בשתי השפות (`go` / `עם`) לא תתוקן לבדה. אבל אם המילה שאחריה תוקנה, למשל `go ,usv`, שתיהן יתוקנו ל־`עם תודה`.

## פרטיות
- אין שום חיבור לרשת.
- שום הקשה לא נשמרת בדיסק. בזיכרון נשמרות רק המילה הנוכחית והמילה הקודמת.
  יש חריג אחד: הפעלה ידנית עם `--debug` כותבת יומן לאיתור תקלות ל־`%TEMP%\TypeCorrection-debug.log`, ויומן זה **כולל טקסט מוקלד**. ההפעלה הרגילה לעולם לא כותבת אותו.
- התוכנה לא פועלת בשדות סיסמה רגילים של Windows, ובתוכנות שברשימת ההחרגה (מנהלי סיסמאות, טרמינל).
  הרשימה נמצאת ב־`%AppData%\TypeCorrection\settings.json`.

## מגבלות ידועות
- שדות סיסמה **באתרים** לא מזוהים. אבל גם בהם שום דבר לא נשמר, ומילה יכולה להשתנות רק אם היא יוצאת מילה תקינה בשפה אחרת.
- בתוכנות שרצות כמנהל מערכת אין תיקון, אלא אם מריצים גם את התוכנה הזו כמנהל.

## פיתוח
```powershell
# בדיקות הלוגיקה מול השפות המותקנות במחשב
dotnet run --project tests/LayoutCheck

# בניית קובץ exe יחיד לתיקייה dist
dotnet publish src/TypeCorrection -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFileApp=true -p:DebugType=none -o dist
```
קבצי הבנייה (`bin` ו־`obj`) נשמרים ב־`%LOCALAPPDATA%\TypeCorrection-build` ולא בתיקיית הפרויקט.
